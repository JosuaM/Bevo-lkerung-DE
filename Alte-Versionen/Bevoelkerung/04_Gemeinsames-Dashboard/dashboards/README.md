# Dashboard

`explorer.js` enthält das einzige Dashboard (ehemals Dashboard 2).

Zwei Diagrammansichten: „Mit & ohne Wanderung“ und „Bevölkerungsbilanz“.
Die Ereignislinien lassen sich mit Maus und Tastatur auswählen. Der ausgewählte Datensatz kommt aus `index.html` (1991–2025).

Die Animationen und gemeinsame Foliennavigation stehen in `index.html`. Es gibt keinen Build-Schritt.
