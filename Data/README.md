# Data – Bevölkerung Deutschland (BRD/DDR), 1950 bis 2025

Alle Reihen: jährlich, lückenlos, 1950 bis zum aktuellsten verfügbaren Jahr (2025). Zusammengestellt am 2026-10-13 aus amtlichen Quellen (Statistisches Bundesamt/Destatis, Statistisches Jahrbuch der DDR, Eurostat). Jeder Ordner enthält eine `QUELLE.md` (Quelle, Spalten, Hinweise) und `Originaldateien/` (unveränderte Quelldateien).

| Ordner | Inhalt | Zeitraum |
|---|---|---|
| 01_DDR_Geburten_und_Sterbefaelle_1950-1989 | Lebendgeborene, Gestorbene, Raten DDR | 1950–1989 (+ Ost bis 2025) |
| 02_BRD_Geburten_und_Sterbefaelle_ab_1990 | Lebendgeborene, Gestorbene Deutschland gesamt | 1990–2025 |
| 03_Bevoelkerung_DDR_1950-1989 | Einwohnerzahl DDR | 1950–1989 (+ Ost bis 2025) |
| 04_Bevoelkerung_Westdeutschland_1950-2025 | Einwohnerzahl BRD/West | 1950–2025 |
| 05_Westdeutschland_Geburten_und_Sterbefaelle_1950-1989 | Lebendgeborene, Gestorbene, Raten BRD (West) | 1950–1989 (+ West bis 2025) |
| 06_Ein-und_Auswanderung_BRD_und_DDR | Zu-/Fortzüge Ausland, Nettowanderung gesamt | 1950–2025 |
| 07_BRD_Geburtenrate | Rohe Geburtenrate und Kinder je Frau (TFR) | 1950–2025 |
| 08_Bevoelkerung_BRD_ab_1990 | Einwohnerzahl Deutschland (+ West/Ost) | 1990–2025 |

Dateiformat: CSV, UTF-8, Komma-getrennt, Dezimalpunkt, leere Zelle = von der Quelle nicht ausgewiesen.
